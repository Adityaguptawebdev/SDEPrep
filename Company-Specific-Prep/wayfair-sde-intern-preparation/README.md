# Wayfair — SDE Intern (India / Bengaluru) Interview Prep

Built from **real candidate reports** (LeetCode Discuss, GeeksforGeeks; mostly 2024–2026) and **Wayfair's own tech blog**. Research date: 19 Oct 2026. Every question links to its source in [sources.md](sources.md).

> ⚠️ Reports are self-written by candidates and the process changes by year and team. Nothing here is internal Wayfair material.

## Intern process (what candidates reported)

```
OA (HackerRank, 2–3 DSA, ~50 min) ─► Technical: DSA or "Moving Day" debug round ─► Hiring Manager ─► HR
```

| Round | What happened |
|---|---|
| **OA** | Jul 2024 intern ("level L0"): 2 questions in 50 min on HackerRank, link sent 30 min before, 6–10 pm IST window [LC-5454797]. Winter intern 2024: 3 DSA (medium, medium, medium-hard) [LC-6167585]. On-campus fresher 2024: two pointers, heap, sieve [LC-6553789]. |
| **Technical** | "Mostly DSA" [LC-6116156], **or** the **"Moving Day" case study**: list the inputs for a scenario, then read the given code, explain it and fix the bugs [LC-6167585, LC-6553789]. |
| **Hiring Manager** | projects, teamwork/conflict, how you take decisions [LC-6553789] |
| **HR** | why Wayfair, strengths/weaknesses, career goals, relocation [LC-6553789] |

- **Stipend:** ₹75,000/month (Bangalore, Jan 2025) [LC-6485830]. An internship converted to a PPO for SDE-1 at ₹25L CTC (2025) [LC-6607371].
- **What Wayfair checks in coding:** readable code, testing, speed, communication. "Better to get working code for a suboptimal solution", and ask for help instead of getting stuck [WF-BLOG-2021].

## If you have little time, do this order

1. **Anagram queries + k-jump maze**: Wayfair's most repeated OA pair (16 and 15 reports, 2023–2025).
2. **Meeting Rooms II**: it was the real intern OA question ("minimum cores").
3. **Moving Day** practice: a round that is unique to Wayfair.
4. **Coupon for Category**: Wayfair's favourite live-coding question (13 reports, mostly SE-II/III).
5. Two project stories + "Why Wayfair" for the HM and HR rounds.

**Code check:** every Java block was compiled and tested against a brute-force solution on random inputs.
